# Password Manager

 # What This App Can Do

Save website, email, and password into a JSON file

Generate strong random passwords

Search saved passwords instantly

Copy generated passwords automatically

Simple and clean Tkinter GUI

# How It Works

# Password Generator

When I click the “Generate Password” button:

It creates a random mix of letters + numbers + symbols

Shuffles everything

Shows the password in the box

Automatically copies it to my clipboard

# Saving Passwords

When I enter:

Website

Email/Username

Password

The app asks me for confirmation and then:

Saves everything in Credentials.json

Creates the file automatically if it doesn’t exist

# Searching Passwords

I just type the website name and click Search.
If the website exists in the JSON file:

It shows the email and password in a popup.
If not:

It tells me “Account not found!”
